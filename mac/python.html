12 · Python และ venv

ใช้เวอร์ชันตามทีม แยกแพ็กเกจแต่ละโปรเจกต์

ในหน้านี้ตรวจก่อนvenvactivatepipModuleNotFoundErrorข้อกำหนดpip install ผ่านแต่ยังผิดตัวอย่างพร้อมคำอธิบาย

ตรวจก่อน

command -v python3 และ --version ดูของเดิม หากเสนอ developer tools ให้ตรวจวิธีทีมก่อน ไม่เปลี่ยน Python ระบบเพื่อแก้งานเดียว

venv

เป็น directory runtime/packages ไม่ใช่ที่เก็บ source ตัวที่เรียก -m venv เป็นฐานของ environment เลือกเวอร์ชันถูกก่อนสร้าง

activate

source .venv/bin/activate เปลี่ยน PATH shell นี้ เปิด Terminal ใหม่ต้อง activate ใหม่ หรือเรียก .venv/bin/python ตรงได้ ไม่ copy ข้ามเครื่องให้สร้างใหม่

pip

python -m pip ผูกกับ interpreter นั้น ติดตั้งตาม requirements/source ที่อนุมัติ แพ็กเกจอาจรันโค้ดภายนอก ไม่ใช้ sudo pip

ModuleNotFoundError

ตรวจ sys.executable กับ pip --version อยู่ environment เดียวกัน ชื่อ import อาจต่างชื่อ package อย่าเดาชื่อคล้ายแล้วติดตั้ง

ข้อกำหนด

requirements/lock ตามทีม pip freeze บอกของที่ลง ไม่พิสูจน์ว่าจำเป็นทุกตัว .gitignore กัน .venv .env __pycache__ และข้อมูลที่ไม่ควร commit

pip install ผ่านแต่ยังผิด

อ่าน path จาก python -m pip --version แล้วเทียบกับ python -c "import sys; print(sys.executable)" หากเป็นคนละงานให้กลับ Folder ที่ถูกและ activate ใหม่ ถ้าเป็นแพ็กเกจที่ต้อง compile และ error architecture ให้เก็บเวอร์ชัน Python ชื่อแพ็กเกจ และ error ให้ทีมดู ไม่สุ่มติดตั้ง compiler หลายตัวหรือใช้รุ่น package ต่างจาก lockfile

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · อ่านข้อมูล

ดูรุ่น

python3 --version

เทียบ README ไม่จำเป็นต้องใหม่สุด

Terminal · สร้างไฟล์/ตั้ง shell

สร้าง environment

python3 -m venv .venv
source .venv/bin/activate

ในรากโปรเจกต์ -m เรียก module .venv คือ directory source โหลดใน shell นี้

Terminal · อ่านข้อมูล

ตรวจ pip

python -m pip --version

ต้องชี้ .venv เดียวกันก่อน install

Terminal · ดาวน์โหลดและติดตั้ง

ติดตั้ง requirements

python -m pip install -r requirements.txt

ใช้ไฟล์ที่ตรวจแล้วกับ source ที่อนุมัติ -r อ่านรายการ ถ้า TLS error ส่ง IT ไม่ข้ามตรวจ

Terminal · ตั้ง shell

ออก environment

deactivate

คืน PATH ไม่ลบ environment

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
