15 · แก้ปัญหาให้ตรงจุด

เริ่มจาก error ตำแหน่งและสิ่งที่เปลี่ยน อย่าแก้หลายอย่างพร้อมกัน ใช้ช่องค้นหาทั้งเล่มหาอาการได้

ในหน้านี้command not foundNo such file or directoryPermission deniedSSL certificate proxyAddress already in useBad CPU typeแอปค้างมี package แต่ import ไม่ได้ถามทีมแม่แบบข้อความส่งพี่หรือ IT

command not found

ดูสะกดและ command -v แอปเปิดได้แต่ CLI ไม่พบอาจ PATH เช่น code ถ้า runtime ไม่มีใช้วิธีทีม

No such file or directory

pwd/ls ดูชื่อจริง Quotes รอบช่องว่าง ตรวจ report.py.txt และโค้ดอ้าง cwd หรือ __file__

Permission denied

ดูเป้าหมาย/สิทธิ์แอป ไม่เติม sudo หรือ chmod ครอบจักรวาล หาก managed ส่ง IT

SSL certificate proxy

ตรวจเครือข่ายและ package source เก็บเวลา host/error ไม่มี token ให้ IT ไม่ด่วนสรุป Zscaler เสียหรือปิด TLS

Address already in use

lsof ดู process หาก server ตัวเองกลับ Terminal เดิม Control+C ไม่รู้เจ้าของอย่าหยุด เปลี่ยน port ตามโปรเจกต์ได้

Bad CPU type

ตรวจ Apple silicon/Universal และ runtime/dependency ให้ตรง About This Mac กับ uname -m ช่วย อย่าผสม Intel/ARM environment

แอปค้าง

ดู Activity Monitor ก่อน Force Quit อาจเสียงานไม่บันทึก ไม่หยุด agent บริษัทเพราะชื่อไม่คุ้น

มี package แต่ import ไม่ได้

เทียบ interpreter editor กับ sys.executable/pip อาจคนละ environment ไม่ต้องลงซ้ำทั้งระบบ

ถามทีม

บอกเป้าหมาย ขั้นตอน คำสั่ง error ที่ตัดข้อมูลลับ เวอร์ชันและสิ่งที่ลอง เช่น editor กับ Terminal ชี้ Python ต่างกันควรเลือกตัวใดตามทีม

แม่แบบข้อความส่งพี่หรือ IT

เป้าหมาย: กำลังทำอะไร / จุดที่ติด: ขั้นตอนและชื่อแอป / คำสั่ง: ระบุเฉพาะที่ไม่มี secret / ผลที่เห็น: ข้อความ error แบบเต็มส่วนเกี่ยวข้อง / ผลที่คาด: ควรเกิดอะไร / เครื่องมือ: macOS, runtime และ path ที่จำเป็น / ลองแล้ว: สิ่งที่ทำและผล ส่งตามช่องทางบริษัท ไม่แนบข้อมูลจริงทั้งไฟล์หากตัวอย่างจำลองทำซ้ำปัญหาได้

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
