10 · PATH process environment

ตรวจ executable ที่ใช้ก่อนแก้ปัญหา “ลงแล้วแต่หาไม่เจอ”

ในหน้านี้PATHชั่วคราวถาวร.envProcessExit codeสิทธิ์เมื่อสองหน้าต่างเห็น Python ต่างกันตัวอย่างพร้อมคำอธิบาย

PATH

รายชื่อ directory คั่น : ค้นตามลำดับ command -v บอกตัวที่จะใช้ ถ้าจะเพิ่มต้องรักษาค่าเดิม ไม่แทนทั้งหมดด้วย directory ใหม่

ชั่วคราวถาวร

export มีผล shell นี้และโปรแกรมลูกหลังจากนั้น .zshrc สำหรับ interactive, .zprofile สำหรับ login shell อย่าคัดลอกบล็อกซ้ำทุกไฟล์

.env

zsh ไม่โหลด .env อัตโนมัติ โปรแกรมต้องมีวิธีอ่าน ใช้ secret manager ตามทีม ไม่ใส่ token จริงใน history หรือแสดง env ทั้งหมดเพื่อส่งภาพ

Process

PID คือหมายเลข process Activity Monitor ดู CPU/memory ได้ ก่อนหยุด process ดูว่าเป็นของใคร Local server ตัวเองมักหยุด Control+C ใน Terminal เดิม

Exit code

$? คือสถานะล่าสุด โดยทั่วไป 0 สำเร็จ รันคำสั่งอื่นคั่นจะเปลี่ยนค่า & เริ่ม background jobs ดูงาน shell fg กลับ foreground งานถาวรใช้ระบบทีม

สิทธิ์

Permission denied ไม่ได้แปลว่าต้อง sudo ดู ls -l ก่อน chmod เปลี่ยนสิทธิ์ ไม่ใช้ 777 แก้ทุกอย่าง Python script รัน python script.py โดยไม่ต้องตั้ง executable

เมื่อสองหน้าต่างเห็น Python ต่างกัน

รัน command -v python3 ในทั้งสองหน้าต่าง แล้วดูว่าอันหนึ่ง activate .venv อยู่หรือไม่ เปรียบเทียบเฉพาะ path ที่เกี่ยวข้อง ไม่ส่ง environment ทั้งหมด หากเพิ่งติดตั้ง CLI หน้าต่างเก่าอาจยังมีสภาพแวดล้อมเดิม ลองเปิด Terminal ใหม่ก่อนแก้ .zshrc และอย่าเพิ่มบล็อก PATH ซ้ำไปเรื่อย ๆ

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · อ่านข้อมูล

หา Python

command -v python3

แสดง executable ที่ shell พบ ถ้าว่างตรวจ PATH/ติดตั้ง

Terminal · อ่านข้อมูล

ดู PATH

printf "%s\n" "$PATH"

แต่ละ directory คั่น : quotes รักษาค่าเป็น argument เดียว

Terminal · ตั้งค่า shell

ตั้งตัวแปรจำลอง

export REPORT_MODE=demo
printf "%s\n" "$REPORT_MODE"

ได้ demo ล้างด้วย unset REPORT_MODE

Terminal · อ่านข้อมูล

สถานะล่าสุด

echo $?

รันทันทีหลังคำสั่งเป้าหมาย ไม่รัน ls คั่น

Terminal · อ่านข้อมูล

ตรวจ port

lsof -nP -iTCP:8000 -sTCP:LISTEN

-nP แสดงตัวเลข เลือก TCP8000 ที่ฟัง ถ้าว่างอาจไม่มีหรือไม่มีสิทธิ์เห็น ไม่หยุดโปรแกรม

Terminal · อ่านข้อมูล

ดูงาน shell

jobs

ดูงาน background ของ shell นี้ ไม่ใช่ทุก process ในเครื่อง

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
