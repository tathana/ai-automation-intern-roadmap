07 · Terminal ตั้งแต่ศูนย์

Terminal เป็นหน้าต่าง shell เช่น zsh ตีความคำสั่งแล้วเรียก Python/Git อีกที

ในหน้านี้Promptคำสั่งWorking directoryPython REPLปุ่มช่วยเงียบวิธีอ่านตัวอย่างในหนังสือตัวอย่างพร้อมคำอธิบาย

Prompt

เปิดผ่าน Spotlight ชื่อผู้ใช้ เครื่อง path และ % ที่เห็นคือข้อความรอรับคำสั่ง ไม่ต้องพิมพ์ตาม ตัวอย่างเล่มนี้ไม่มี %/$ นำหน้า

คำสั่ง

ls -la . มีโปรแกรม ls, options -la, เป้าหมาย . คั่นช่องว่างแล้ว Enter หลายบรรทัดให้อ่านและรันทีละบรรทัดก่อน เพราะอาจพึ่งผลก่อนหน้า

Working directory

แต่ละ Terminal มีที่อยู่เอง เปิด Finder ไม่ย้าย shell ตาม ใช้ pwd ตรวจและ cd ก่อนรัน relative path

Python REPL

เห็น >>> คือ Python พิมพ์ exit() กลับ shell คำสั่ง cd ไม่ใช่ Python และ import csv ไม่ใช่ shell

ปุ่มช่วย

Tab เติม path ลูกศรขึ้นเรียกประวัติ Control+C หยุด foreground program Command+C คัดลอกข้อความ ถ้า dquote> อาจ quotes ไม่ครบ ยกเลิกด้วย Control+C

เงียบ

mkdir/cp อาจสำเร็จไม่มีข้อความ เมื่อ prompt กลับใช้ ls ตรวจ ถ้ายังไม่กลับอาจรันหรือรอ input Password บาง prompt ไม่แสดงตัวอักษร แต่ต้องรู้ก่อนว่าคำสั่งนั้นจำเป็นและอนุญาต

วิธีอ่านตัวอย่างในหนังสือ

ป้าย Terminal หมายถึงพิมพ์ในหน้าต่างที่เป็น shell ไม่ใช่ช่องค้น Spotlight หรือช่อง Python >>> ป้ายไฟล์หมายถึงสร้างไฟล์ใน editor แล้ววางเนื้อหาไว้ในนั้น คำสั่งที่มีหลายบรรทัดให้อ่านคำอธิบายและทำทีละบรรทัด ถ้าบรรทัดหนึ่ง error ให้หยุดตรวจ ไม่ใช้ผลลัพธ์ที่คาดเดาไปต่อ

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · อ่านข้อมูล

ดูตำแหน่ง

pwd

ผลเป็น absolute path เช่น /Users/ชื่อผู้ใช้

Terminal · อ่านข้อมูล

อ่านคู่มือ

man ls

เลื่อน Space ค้นด้วย / แล้ว Enter กด q ออก ตรวจ options ที่รองรับในเครื่อง

Terminal · แสดงผล

ล้างหน้าจอ

clear

ไม่ลบไฟล์หรือประวัติคำสั่ง

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
