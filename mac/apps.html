06 · ติดตั้งและถอนแอป

ใช้พอร์ทัลบริษัทก่อน ขั้นตอนนี้สำหรับแอปที่อนุญาตแล้ว

ในหน้านี้เลือกแอปลำดับ.dmg.pkgถอน/อัปเดตถูกบล็อกติดตั้ง Python เมื่อทีมอนุมัติแล้ว

เลือกแอป

เริ่ม browser/editor/Python/Git ตามทีม Node เมื่อมี JavaScript Docker เมื่อใช้ container ไม่ลง runtime ซ้ำหลายชุดเผื่อทุกอย่าง

ลำดับ

ยืนยันแอปและรุ่น → แหล่งทางการที่อนุญาต → Apple silicon/Universal → อ่านสิทธิ์ → ติดตั้ง → เปิดตรวจ Admin ไม่แทนการอนุมัติ

.dmg

Disk image เหมือนไดรฟ์ชั่วคราว หลายแอปให้ลากเข้า Applications แล้วเปิดจาก Applications และ Eject image แต่บางตัวมี installer ภายใน อ่านหน้าต่างจริง

.pkg

Installer อาจเพิ่ม service และไฟล์หลายที่ อ่านคำขอและให้ IT ช่วยเมื่อจำเป็น App Store ใช้บัญชีตามนโยบาย ไม่ต้องเปิด sync ส่วนตัวเพื่อทดลอง

ถอน/อัปเดต

แอปทั่วไปบางตัวลากจาก Applications ไป Trash ได้ แอป service ใช้ uninstaller ทางการ/IT Runtime อัปเกรดอาจกระทบ dependency อ่าน README ก่อน

ถูกบล็อก

เก็บชื่อ เวอร์ชัน แหล่ง และ error ไม่ใช้สูตรลบ quarantine/ปิด Gatekeeper เพื่อข้ามคำเตือนที่ยังไม่เข้าใจ

ติดตั้ง Python เมื่อทีมอนุมัติแล้ว

ถ้ามีพอร์ทัลใช้แพ็กเกจที่ทีมระบุ ถ้าทีมกำหนด installer จาก python.org ให้เลือกเวอร์ชันตามงานและตัว macOS ที่รองรับ Apple silicon เปิด .pkg แล้วทำตามขั้นตอนที่ IT อนุญาต เปิด Terminal ใหม่ ตรวจ python3 --version และ command -v python3 ก่อนสร้าง venv หากทีมใช้ Homebrew หรือ version manager ให้ใช้วิธีนั้นแทน อย่าติดตั้งซ้อนหลายช่องทางเพื่อให้เลขเวอร์ชันเปลี่ยน

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
