04 · Finder และไฟล์งาน

รู้ตำแหน่งไฟล์ก่อนสั่งโปรแกรมอ่าน ตัวอย่างใช้ ~/mac-lab ส่วนงานจริงใช้พื้นที่ทีมอนุญาต

ในหน้านี้โฟลเดอร์งานPathย้ายไฟล์ไฟล์ซ่อนZIP และ Trashชื่อไฟล์กับชนิดไฟล์ตัวอย่างพร้อมคำอธิบาย

โฟลเดอร์งาน

แยกจาก Downloads อย่าเก็บข้อมูลบริษัทลง cloud ส่วนตัวเพียงเพราะเหมือนโฟลเดอร์ local ถามระบบสำรองของทีมก่อน

Path

Command+Shift+G ไป path เช่น ~/mac-lab เครื่องหมาย ~ คือ home ส่วน . คือ directory ปัจจุบัน และ .. คือแม่ เปิด View → Show Path Bar ช่วยดูตำแหน่ง

ย้ายไฟล์

Command+C แล้ว Command+V คัดลอก Option+Command+V ย้ายไฟล์ที่คัดลอกไว้ใน Finder Return เปลี่ยนชื่อ การเปลี่ยน .xlsx เป็น .csv ไม่ได้แปลงข้อมูล

ไฟล์ซ่อน

Space Quick Look, Command+I Get Info ดูขนาด/ชนิด Finder Settings → Advanced ตั้งแสดง extension ได้ Command+Shift+. แสดงชื่อขึ้นต้นด้วยจุด เช่น .env

ZIP และ Trash

คลิกขวา Compress ทำ ZIP ตรวจไม่มีข้อมูลลับก่อนแชร์ Trash กู้ได้ก่อนล้างถัง แต่ rm ไม่ผ่าน Trash External drive ควร Eject ก่อนถอด

ชื่อไฟล์กับชนิดไฟล์

ไฟล์ report.csv เป็นข้อความตาราง ส่วน report.xlsx เป็นโครงสร้าง workbook การเปลี่ยนชื่อไม่แปลงชนิด ถ้าทีมขอ CSV ให้ Export/Save As จากแอปที่รองรับแล้วตรวจ encoding และคอลัมน์ก่อนใช้ หากดับเบิลคลิกเปิดผิดแอป ใช้คลิกขวา → Open With เพื่อเลือกโดยไม่ต้องเปลี่ยน default ทันที

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

จุดคือ directory ที่ Terminal อยู่ Finder เปิดที่เดียวกัน
