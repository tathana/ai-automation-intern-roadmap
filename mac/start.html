APPLE SILICON M1 · เรียนทีละขั้น / เปิดค้นตอนใช้งาน

00 · รู้จัก Mac บริษัท

ใช้ Apple silicon M1 เป็นฐาน ส่วน macOS 26.6.2 เป็นข้อมูลที่ต้าแจ้ง ยังไม่ได้ตรวจจากเครื่องจริง ให้ดู Apple → About This Mac และเทียบ ProductVersion ก่อนอ้างชื่อเมนู

ในหน้านี้ตรวจเครื่องApple siliconช่องทางบริษัทMDM และ Zscalerคำถามพร้อมใช้ทำโน้ตเครื่องของเราตัวอย่างพร้อมคำอธิบาย

ตรวจเครื่อง

ดู Chip, Memory และ macOS ใน About This Mac จดเฉพาะข้อมูลที่ใช้แก้ปัญหา ไม่ต้องส่ง serial number ให้คู่มือนี้ การค้นใน System Settings ช่วยเมื่อชื่อเมนูเปลี่ยน

Apple silicon

M1 ใช้ ARM เลือกแอป Apple silicon/arm64 หรือ Universal ตามทีม ส่วน Intel/x86_64 เป็นอีกสถาปัตยกรรม Rosetta อาจแปลแอป Intel ได้ แต่ไม่ควรเริ่มด้วยการเปิดทุกอย่างผ่าน Rosetta

ช่องทางบริษัท

ถามพอร์ทัลติดตั้ง เวอร์ชัน runtime และ extension ที่อนุญาต การใช้เมลบริษัทไม่ได้แปลว่าทุก AI service รับข้อมูลบริษัทได้ ถามที่เก็บ source, repository และระดับข้อมูลที่ใช้กับ AI ได้

MDM และ Zscaler

MDM อาจล็อกการตั้งค่า Zscaler อาจเกี่ยวกับเครือข่าย แต่ยังสรุปสาเหตุ error ไม่ได้ เก็บเวลา ขั้นตอน และ error ส่ง IT ไม่ลบ agent หรือปิดตรวจ certificate

คำถามพร้อมใช้

พี่ครับ ทีมติดตั้ง VS Code กับ Python ผ่านช่องทางไหน ใช้เวอร์ชันอะไร และมี extension/package source ที่อนุญาตไหมครับ โค้ดกับข้อมูลควรเก็บที่ไหนครับ

ทำโน้ตเครื่องของเรา

เปิดแอปโน้ตที่บริษัทอนุญาต สร้างหัวข้อ “เครื่องมือทำงาน” แล้วจด 1) รุ่น macOS จาก About This Mac 2) ช่องทางติดต่อ IT 3) editor และ runtime ที่ทีมใช้ 4) โฟลเดอร์/repository งาน 5) วิธีเข้าระบบภายใน เวลามีปัญหาจะหยิบข้อมูลนี้มาประกอบได้ทันทีโดยไม่ต้องไล่ถามใหม่ทั้งหมด

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · อ่านข้อมูล

ดูเวอร์ชัน

sw_vers

ผลมี ProductVersion เทียบ About This Mac ไม่เปลี่ยนค่าเครื่อง

Terminal · อ่านข้อมูล

ดูสถาปัตยกรรม

uname -m

Native M1 ควร arm64 ถ้า x86_64 อาจผ่าน Rosetta ดู Chip ประกอบ

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
