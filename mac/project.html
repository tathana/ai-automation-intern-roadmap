ในหน้านี้เตรียมInputโปรแกรมผลทดสอบผิดต่อยอดอธิบายโค้ดทีละช่วงตัวอย่างพร้อมคำอธิบาย

เตรียม

สร้าง ~/mac-lab/report-demo ที่ไม่มีงานเดิม เปิด Folder นี้ใน editor ทุกคำสั่งบทนี้จากรากนี้ เปิด Terminal ใหม่ต้อง cd กลับ

Input

สร้าง data/requests.csv UTF-8 ตามตัวอย่าง หนึ่งแถวหนึ่ง request ID ไม่ซ้ำ status done/pending นับรายการ ไม่ใช่เงินหรือประวัติเหตุการณ์

โปรแกรม

สร้าง report.py ที่ราก โปรแกรมตรวจ header, ID และ status ก่อนนับ ใช้ Path(__file__) อ้างที่อยู่สคริปต์

ผล

ต้องเห็น Wrote และ total 3 done 2 pending 1 หากรอบใหม่ error ไฟล์เก่าอาจยังอยู่ ต้องดูว่ารอบนี้สำเร็จก่อนใช้ผล

ทดสอบผิด

สำรอง CSV เปลี่ยน status เป็น unknown ต้อง ValueError คืนแล้วทำ ID ซ้ำต้องหยุด สุดท้ายคืนข้อมูลเดิม การเปิด HTML ได้อย่างเดียวไม่พิสูจน์ว่าคำนวณถูก

ต่อยอด

งานจริงเพิ่มนิยามข้อมูล สิทธิ์ log ตรวจรับ และ scheduler กับทีม ตัวอย่างยังไม่ใช่ production อ่านเล่ม Automation ต่อ

อธิบายโค้ดทีละช่วง

with เปิดไฟล์และปิดให้เมื่ออ่านเสร็จ DictReader แปลงแต่ละแถวเป็น dictionary จาก header ส่วน seen เป็น set เก็บ ID ที่พบเพื่อจับซ้ำ Counter รวมจำนวนตาม status หลังตรวจข้อมูลทั้งหมดแล้วจึงประกอบ HTML และ write_text เขียนไฟล์ output ไม่ต้องลง pandas เพื่อทำงานเล็กนี้ การทดลองเล็กช่วยแยกปัญหาเครื่องมือออกจาก logic ธุรกิจ

ไฟล์ · report.py

โปรแกรมรายงาน

from pathlib import Path
from collections import Counter
import csv

base = Path(__file__).resolve().parent
with (base / "data" / "requests.csv").open(encoding="utf-8-sig", newline="") as stream:
    reader = csv.DictReader(stream)
    if reader.fieldnames != ["request_id", "status"]:
        raise ValueError("Expected columns: request_id,status")
    rows = list(reader)

seen = set()
for row in rows:
    if not row["request_id"] or row["request_id"] in seen:
        raise ValueError("Missing or duplicate request_id")
    if row["status"] not in {"done", "pending"}:
        raise ValueError("Unknown status")
    if None in row:
        raise ValueError("Too many columns")
    seen.add(row["request_id"])

counts = Counter(row["status"] for row in rows)
html = (
    '<!doctype html><html lang="en"><meta charset="utf-8">'
    '<title>Demo report</title><h1>Request report</h1>'
    f'<p>Total: {len(rows)}</p>'
    f'<p>Done: {counts["done"]}</p>'
    f'<p>Pending: {counts["pending"]}</p></html>'
)
output = base / "output" / "report.html"
output.parent.mkdir(exist_ok=True)
output.write_text(html, encoding="utf-8")
print(f"Wrote {output}")

วางในไฟล์ที่รากโปรเจกต์ Path หาโฟลเดอร์สคริปต์ DictReader อ่านแถวเป็น dictionary Counter นับสถานะ ตรวจข้อมูลทั้งหมดก่อนเขียนทับ output/report.html ผลแทรกเฉพาะตัวเลข ไม่ใส่ข้อความจาก input ลง HTML
