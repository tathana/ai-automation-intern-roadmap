00 · รู้จัก Mac บริษัท

ดูเวอร์ชัน

อ่านข้อมูล · ผลมี ProductVersion เทียบ About This Mac ไม่เปลี่ยนค่าเครื่อง

sw_vers
ดูสถาปัตยกรรม

อ่านข้อมูล · Native M1 ควร arm64 ถ้า x86_64 อาจผ่าน Rosetta ดู Chip ประกอบ

uname -m

04 · Finder และไฟล์งาน

เปิด cwd ใน Finder

เปิดแอป · จุดคือ directory ที่ Terminal อยู่ Finder เปิดที่เดียวกัน

open .

07 · Terminal ตั้งแต่ศูนย์

ดูตำแหน่ง

อ่านข้อมูล · ผลเป็น absolute path เช่น /Users/ชื่อผู้ใช้

pwd
อ่านคู่มือ

อ่านข้อมูล · เลื่อน Space ค้นด้วย / แล้ว Enter กด q ออก ตรวจ options ที่รองรับในเครื่อง

man ls
ล้างหน้าจอ

แสดงผล · ไม่ลบไฟล์หรือประวัติคำสั่ง

clear

08 · จัดไฟล์ด้วยคำสั่ง

สร้างพื้นที่ฝึก

สร้างโฟลเดอร์ · -p สร้าง parent ที่ขาดและยอมให้ directory มีอยู่แล้ว cd เปลี่ยนที่ pwd ต้องลงท้าย /mac-lab

mkdir -p ~/mac-lab
ดูไฟล์ทั้งหมด

อ่านข้อมูล · -l รายละเอียด -a รวมชื่อขึ้นต้นจุด . และ .. ไม่ใช่ไฟล์งานให้ลบ

ls -la
สร้างไฟล์

เขียนไฟล์ · ถ้าไม่มีสร้างขนาดศูนย์ ถ้ามีเปลี่ยน timestamp ไม่ล้างข้อความ ตรวจ ls -l notes.txt

touch notes.txt
สำเนาและเปลี่ยนชื่อ

เขียนไฟล์ · ทำหลัง touch จะมี notes.txt และ archive-notes.txt -i ถามก่อนทับ

cp -i notes.txt notes-copy.txt
ลบสำเนา

ลบไฟล์ · ตรวจ pwd กับ ls -l archive-notes.txt ก่อน ตอบ y ลบ n ยกเลิก ไม่เข้า Trash

rm -i archive-notes.txt
กลับ home และกลับเดิม

เปลี่ยนตำแหน่ง · ~ คือ home; - กลับ working directory ก่อนหน้า

cd ~

09 · อ่าน ค้น ต่อคำสั่ง

สร้าง log

เขียนทับไฟล์ · ใน ~/mac-lab เท่านั้น \n ขึ้นบรรทัด > ทับ demo.log ถ้ามี

printf "INFO start\nERROR missing field\nINFO done\n" > demo.log
หา error

อ่านข้อมูล · -n เลขบรรทัด ผล 2:ERROR missing field

grep -n "ERROR" demo.log
อ่านแบบเลื่อน

อ่านข้อมูล · /ERROR ค้น n ถัดไป q ออก

less demo.log
ดูท้ายสองบรรทัด

อ่านข้อมูล · ได้ ERROR และ INFO done

tail -n 2 demo.log
หา CSV

อ่านข้อมูล · เริ่มที่ . ค้นชื่อ หากยังไม่มีผลว่างปกติ

find . -name "*.csv"
นับ INFO

อ่านข้อมูล · ส่งสองบรรทัดให้ wc -l ได้ 2

grep "INFO" demo.log | wc -l
เข้า clipboard

เปลี่ยน clipboard · Command+V ได้ Hello Mac แทน clipboard เดิม

printf "Hello Mac" | pbcopy
ค้นด้วย ripgrep

อ่านข้อมูล · ต้องมี rg · ใช้เฉพาะที่ติดตั้งและอนุมัติแล้ว -n เลขบรรทัด ถ้าไม่มีก็ใช้ grep ข้างบนได้

rg -n "ERROR" demo.log

10 · PATH process environment

หา Python

อ่านข้อมูล · แสดง executable ที่ shell พบ ถ้าว่างตรวจ PATH/ติดตั้ง

command -v python3
ดู PATH

อ่านข้อมูล · แต่ละ directory คั่น : quotes รักษาค่าเป็น argument เดียว

printf "%s\n" "$PATH"
ตั้งตัวแปรจำลอง

ตั้งค่า shell · ได้ demo ล้างด้วย unset REPORT_MODE

export REPORT_MODE=demo
สถานะล่าสุด

อ่านข้อมูล · รันทันทีหลังคำสั่งเป้าหมาย ไม่รัน ls คั่น

echo $?
ตรวจ port

อ่านข้อมูล · -nP แสดงตัวเลข เลือก TCP8000 ที่ฟัง ถ้าว่างอาจไม่มีหรือไม่มีสิทธิ์เห็น ไม่หยุดโปรแกรม

lsof -nP -iTCP:8000 -sTCP:LISTEN
ดูงาน shell

อ่านข้อมูล · ดูงาน background ของ shell นี้ ไม่ใช่ทุก process ในเครื่อง

jobs

11 · VS Code พร้อมทำงาน

เปิด Folder

เปิดแอป · ต้องติดตั้ง code ใน PATH ก่อน ไม่พบใช้ File → Open Folder

code .
ตรวจ interpreter

อ่านข้อมูล · หลัง activate ควรลงท้าย .venv/bin/python ของงานนี้

python -c "import sys; print(sys.executable)"

12 · Python และ venv

ดูรุ่น

อ่านข้อมูล · เทียบ README ไม่จำเป็นต้องใหม่สุด

python3 --version
สร้าง environment

สร้างไฟล์/ตั้ง shell · ในรากโปรเจกต์ -m เรียก module .venv คือ directory source โหลดใน shell นี้

python3 -m venv .venv
ตรวจ pip

อ่านข้อมูล · ต้องชี้ .venv เดียวกันก่อน install

python -m pip --version
ติดตั้ง requirements

ดาวน์โหลดและติดตั้ง · ใช้ไฟล์ที่ตรวจแล้วกับ source ที่อนุมัติ -r อ่านรายการ ถ้า TLS error ส่ง IT ไม่ข้ามตรวจ

python -m pip install -r requirements.txt
ออก environment

ตั้ง shell · คืน PATH ไม่ลบ environment

deactivate

13 · Git Node Homebrew Docker

ดู Git

อ่านข้อมูล · ใน repository diff แสดง tracked ที่ยังไม่ stage ไฟล์ใหม่เปิดดูเอง

git status
ตรวจ staged/remote

อ่านข้อมูล · ดูสิ่งที่จะ commit และปลายทาง fetch/push

git diff --staged
ดู Node/npm

อ่านข้อมูล · เมื่อติดตั้งผ่านช่องทางทีมแล้ว

node --version
ดู scripts

อ่านรายการ · จาก directory มี package.json ไม่ระบุชื่อ script เพื่อดูรายการ

npm run
หา Homebrew

อ่านข้อมูล · ว่างไม่ได้แปลว่าจำเป็นต้องติดตั้ง

command -v brew

14 · CSV → Report ทำตามได้

สร้างห้องทดลอง

สร้างไฟล์/ตั้ง shell · ใช้ Python ที่อนุมัติ เปิด Folder นี้ใน editor

mkdir -p ~/mac-lab/report-demo/data ~/mac-lab/report-demo/output
ข้อมูลจำลอง

ไฟล์ · data/requests.csv · วางในไฟล์ UTF-8 ไม่ใช่ Terminal header กับสามแถว

request_id,status
โปรแกรมรายงาน

ไฟล์ · report.py · วางในไฟล์ที่รากโปรเจกต์ Path หาโฟลเดอร์สคริปต์ DictReader อ่านแถวเป็น dictionary Counter นับสถานะ ตรวจข้อมูลทั้งหมดก่อนเขียนทับ output/report.html ผลแทรกเฉพาะตัวเลข ไม่ใส่ข้อความจาก input ลง HTML

from pathlib import Path
รันและเปิด

รัน/เขียนผล · เปิดต่อเมื่อ Python สำเร็จ หาก error อย่าใช้ผลเก่า

python report.py
ไม่เก็บเข้า Git

ไฟล์ · .gitignore · งานจริงเพิ่มตามทีม ไฟล์ tracked แล้วไม่ได้ถูกเอาออกโดยอัตโนมัติ

.venv/
