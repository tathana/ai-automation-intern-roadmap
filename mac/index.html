หนังสือสำหรับต้า — เริ่มจาก Windows มาสู่ Mac M1 ที่บริษัทดูแล อธิบายสิ่งที่ต้องทำ เหตุผล ผลที่ควรเห็น และวิธีตรวจเมื่อไม่เหมือนตัวอย่าง

macOS 26.6.2 เป็นเวอร์ชันที่ผู้ใช้แจ้ง โปรดยืนยันที่ About This Mac คำสั่งที่เปลี่ยนไฟล์มีป้ายบอก และตัวอย่างใช้ข้อมูลจำลอง

00 · รู้จัก Mac บริษัท

ใช้ Apple silicon M1 เป็นฐาน ส่วน macOS 26.6.2 เป็นข้อมูลที่ต้าแจ้ง ยังไม่ได้ตรวจจากเครื่องจริง ให้ดู Apple → About This Mac และเทียบ ProductVersion ก่อนอ้างชื่อเมนู

เปิดบทเรียน →

01 · จาก Windows มา Mac

เริ่มจากเปิดแอป สลับงาน และบันทึกไฟล์ ไม่ต้องจำทุกเมนูวันแรก

เปิดบทเรียน →

02 · คีย์บอร์ด ภาษา แทร็กแพด

⇧ คือ Shift จำปุ่มที่ใช้บ่อยแล้วเปิดอ้างอิงที่เหลือเมื่อจำเป็น

เปิดบทเรียน →

03 · หน้าต่าง Spaces จอนอก

จัด editor ข้างคู่มือก่อนแล้วค่อยเพิ่มพื้นที่ แยกงานอย่างที่ตามหาได้

เปิดบทเรียน →

04 · Finder และไฟล์งาน

รู้ตำแหน่งไฟล์ก่อนสั่งโปรแกรมอ่าน ตัวอย่างใช้ ~/mac-lab ส่วนงานจริงใช้พื้นที่ทีมอนุญาต

เปิดบทเรียน →

05 · ตั้งค่าและประชุม

ตั้งภาษา ตัวหนังสือ และอุปกรณ์ประชุมก่อน ค่าที่ถูกจัดการโดยองค์กรให้ IT ช่วย

เปิดบทเรียน →

06 · ติดตั้งและถอนแอป

ใช้พอร์ทัลบริษัทก่อน ขั้นตอนนี้สำหรับแอปที่อนุญาตแล้ว

เปิดบทเรียน →

07 · Terminal ตั้งแต่ศูนย์

Terminal เป็นหน้าต่าง shell เช่น zsh ตีความคำสั่งแล้วเรียก Python/Git อีกที

เปิดบทเรียน →

08 · จัดไฟล์ด้วยคำสั่ง

ฝึกไฟล์จำลองใน ~/mac-lab ตรวจผลทุกขั้น ชื่อมีช่องว่างครอบคำพูดตรง

เปิดบทเรียน →

09 · อ่าน ค้น ต่อคำสั่ง

อ่าน log ส่วนที่เกี่ยวข้องก่อนถามทีม ใช้ข้อมูลจำลองเรียน pipe และ redirect

เปิดบทเรียน →

13 · Git Node Homebrew Docker
