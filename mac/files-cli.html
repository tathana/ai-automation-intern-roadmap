08 · จัดไฟล์ด้วยคำสั่ง

ฝึกไฟล์จำลองใน ~/mac-lab ตรวจผลทุกขั้น ชื่อมีช่องว่างครอบคำพูดตรง

ในหน้านี้Path สองแบบพื้นที่ฝึกcp/mvrmMac/Linuxก่อนย้ายไฟล์ที่มีช่องว่างตัวอย่างพร้อมคำอธิบาย

Path สองแบบ

Absolute เริ่ม / ส่วน data/input.csv เริ่มจาก cwd ../ ถอยหนึ่งระดับ ใช้ ~ แทน home หรือ "$HOME/..." หากต้องครอบ path

พื้นที่ฝึก

ถ้ามีงานเดิมในชื่อ mac-lab ให้เลือกชื่อใหม่ เปิด Terminal ใหม่ต้อง cd กลับ ตัวอย่างไม่ควรใช้กับข้อมูลจริง

cp/mv

cp คัดลอก mv ย้าย/เปลี่ยนชื่อ ปลายทางผิดอาจทับไฟล์ ตัวอย่าง -i ถามเมื่อชนชื่อ ตอบ n ถ้าไม่แน่ใจ

rm

ไม่ผ่าน Trash และไม่มี undo แบบ editor ฝึกกับสำเนาหนึ่งไฟล์ที่ตรวจชื่อแล้ว ไม่เริ่มด้วย rm -rf หรือ * แบบครอบคลุม

Mac/Linux

Options บางตัวต่างกัน ใช้ man ของเครื่อง ไม่เติม sudo แก้ option ผิด รักษาตัวเล็กใหญ่ชื่อไฟล์ให้ตรงเพราะปลายทางอาจแยก case

ก่อนย้ายไฟล์ที่มีช่องว่าง

สมมติมีไฟล์ชื่อ my report.txt ให้พิมพ์ ls -l "my report.txt" เพื่อดูว่ามีจริง ก่อนใช้ cp -i "my report.txt" "my report copy.txt" โดยใช้เครื่องหมายคำพูดตรง ไม่ใช้คำพูดโค้งจากเอกสาร อย่า copy คำสั่งนี้หากไม่มีไฟล์ตัวอย่างชื่อนั้น การลากไฟล์จาก Finder ลง Terminal ช่วยเติม path ได้ แต่ยังต้องตรวจคำสั่งทั้งบรรทัดก่อน Enter

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · สร้างโฟลเดอร์

สร้างพื้นที่ฝึก

mkdir -p ~/mac-lab
cd ~/mac-lab
pwd

-p สร้าง parent ที่ขาดและยอมให้ directory มีอยู่แล้ว cd เปลี่ยนที่ pwd ต้องลงท้าย /mac-lab

Terminal · อ่านข้อมูล

ดูไฟล์ทั้งหมด

ls -la

-l รายละเอียด -a รวมชื่อขึ้นต้นจุด . และ .. ไม่ใช่ไฟล์งานให้ลบ

Terminal · เขียนไฟล์

สร้างไฟล์

touch notes.txt

ถ้าไม่มีสร้างขนาดศูนย์ ถ้ามีเปลี่ยน timestamp ไม่ล้างข้อความ ตรวจ ls -l notes.txt

Terminal · เขียนไฟล์

สำเนาและเปลี่ยนชื่อ

cp -i notes.txt notes-copy.txt
mv -i notes-copy.txt archive-notes.txt

ทำหลัง touch จะมี notes.txt และ archive-notes.txt -i ถามก่อนทับ

Terminal · ลบไฟล์

ลบสำเนา

rm -i archive-notes.txt

ตรวจ pwd กับ ls -l archive-notes.txt ก่อน ตอบ y ลบ n ยกเลิก ไม่เข้า Trash

Terminal · เปลี่ยนตำแหน่ง

กลับ home และกลับเดิม

cd ~
cd -

~ คือ home; - กลับ working directory ก่อนหน้า

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
