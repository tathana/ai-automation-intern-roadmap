11 · VS Code พร้อมทำงาน

Editor runtime และ extension เป็นคนละส่วน เลือก interpreter ให้ตรงโปรเจกต์

ในหน้านี้ติดตั้งเปิด FolderExtensioncode CLIInterpreterDebugบันทึกจากไฟล์เปล่าถึง Run ครั้งแรกตัวอย่างพร้อมคำอธิบาย

ติดตั้ง

ใช้พอร์ทัลบริษัทก่อน ถ้าดาวน์โหลดเองได้ใช้ VS Code ทางการ Apple silicon/Universal เปิด .dmg ลากไป Applications แล้วเปิดจากนั้น ถ้าติดสิทธิ์ใช้ IT

เปิด Folder

File → Open Folder ที่รากโปรเจกต์ เพื่อ Explorer/search/Git มีบริบทเดียวกัน Workspace Trust เกี่ยวกับโค้ดและ tasks ที่อาจรันได้ เชื่อถือเมื่อรู้ที่มา

Extension

ใช้ Python extension ของ Microsoft ที่ทีมอนุมัติ ตรวจ publisher โดยเฉพาะ AI extension ที่ส่งข้อมูลออก ไม่ต้องลง pack ใหญ่

code CLI

Command+Shift+P ค้น Shell Command: Install 'code' command in PATH เลือกแล้วเปิด Terminal ใหม่ ถ้าถูกบล็อกยังใช้ File → Open Folder ระหว่าง IT ช่วยได้

Interpreter

สร้าง .venv แล้ว Python: Select Interpreter เลือก .venv/bin/python เปิด Terminal ใหม่ตรวจ sys.executable ปุ่ม Run อาจใช้คนละตัวถ้าตั้งผิด

Debug

ตั้ง breakpoint ข้างเลขบรรทัด Run and Debug ตาม extension ที่อนุญาต Step Over เดินและดู Variables ถ้า error import ตรวจ environment ก่อน business logic

บันทึก

Command+S ก่อนรัน จุดบนแท็บอาจบอกยังไม่บันทึก Source Control ดู diff ก่อน stage ตรวจ .env/input ไม่รวมไฟล์ใหม่ทั้งหมดอัตโนมัติ

จากไฟล์เปล่าถึง Run ครั้งแรก

เปิด Folder → New File ตั้งชื่อ hello.py → พิมพ์ print("Hello Mac") → Command+S → เลือก Python Interpreter ตาม environment → เปิด Terminal ของ editor แล้วรัน python hello.py หลัง activate ควรเห็น Hello Mac หนึ่งบรรทัด หากปุ่ม Run ได้ผลแต่ Terminal ไม่ได้ ให้ตรวจ interpreter ทั้งสองส่วน แยกปัญหาการบันทึกกับปัญหา runtime

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · เปิดแอป

เปิด Folder

code .

ต้องติดตั้ง code ใน PATH ก่อน ไม่พบใช้ File → Open Folder

Terminal · อ่านข้อมูล

ตรวจ interpreter

python -c "import sys; print(sys.executable)"

หลัง activate ควรลงท้าย .venv/bin/python ของงานนี้

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
