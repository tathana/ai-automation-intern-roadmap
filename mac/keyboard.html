02 · คีย์บอร์ด ภาษา แทร็กแพด

⇧ คือ Shift จำปุ่มที่ใช้บ่อยแล้วเปิดอ้างอิงที่เหลือเมื่อจำเป็น

ในหน้านี้ไทยอังกฤษแทร็กแพดเลือกข้อความภาพหน้าจอฝึกสองนาทีเมื่อ shortcut ไม่ทำงาน

ไทยอังกฤษ

System Settings → Keyboard หา Text Input/Input Sources เพิ่ม layout ที่ถนัด ตรวจ Keyboard Shortcuts → Input Sources ว่าใช้ปุ่มใดสลับ เพราะอาจปรับไว้ Globe/Fn อาจตั้งทำอย่างอื่น

แทร็กแพด

System Settings → Trackpad ดู Secondary click เช่นแตะสองนิ้ว ลอง Natural scrolling แล้วเลือกทิศที่ถนัด มีภาพตัวอย่างท่าทางใน Settings ให้ลองตาม

เลือกข้อความ

Shift+ลูกศรขยายส่วนเลือก Option+ซ้าย/ขวาขยับเป็นคำในหลายแอป Command+ซ้าย/ขวาไปต้นท้ายบรรทัด Editor และ Terminal อาจผูกปุ่มต่างกัน ดูเมนูแอปประกอบ

ภาพหน้าจอ

Command+Shift+5 เลือกพื้นที่และดู Options ว่าบันทึกที่ไหน ก่อนส่ง error ครอปส่วนที่จำเป็น ปิด token ข้อมูลลูกค้า และแชตที่ไม่เกี่ยวข้อง หากบริษัทจำกัด capture ใช้วิธีส่งข้อความที่อนุญาต

ฝึกสองนาที

เปิดโน้ต สลับภาษา คัดลอก วาง Undo และจับภาพเฉพาะโน้ต เป้าหมายคือรู้ตำแหน่งปุ่มด้วยมือ ไม่ใช่ท่องรายการทั้งหมด

เมื่อ shortcut ไม่ทำงาน

ลองคลิกพื้นที่งานให้แอป active ก่อน แล้วดูว่าภาษาปัจจุบันทำให้ปุ่มที่กดต่างจากที่คิดหรือไม่ เปิดเมนู Edit/View เพื่อดู shortcut ที่แอปแสดง หากใช้คีย์บอร์ด Windows ภายนอก ตำแหน่ง modifier อาจทำให้สับสน ตรวจ Keyboard → Keyboard Shortcuts → Modifier Keys ตามตัวเลือกที่ระบบมี แก้เฉพาะอุปกรณ์ที่ใช้แล้วทดลองคัดลอกในโน้ตก่อน
