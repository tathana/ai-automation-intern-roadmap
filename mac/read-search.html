09 · อ่าน ค้น ต่อคำสั่ง

อ่าน log ส่วนที่เกี่ยวข้องก่อนถามทีม ใช้ข้อมูลจำลองเรียน pipe และ redirect

ในหน้านี้วิธีอ่านค้นอะไรPipeผลว่างEncodingอ่าน log อย่างมีคำถามตัวอย่างพร้อมคำอธิบาย

วิธีอ่าน

cat ไฟล์สั้น less ไฟล์ยาว head ต้น tail ท้าย ไม่ cat ไบนารีหรือ log มหาศาล และไม่ส่ง log บริษัทไปที่ไม่อนุญาต

ค้นอะไร

find ค้นชื่อ/path grep ค้นเนื้อหา Quotes รอบ "*.csv" กัน shell ขยายก่อน find หากใช้ rg ต้องมีติดตั้งก่อน

ตัว

ผลว่าง

grep ไม่พบอาจเงียบและ exit code 1 No such file ให้ดู pwd/ls ก่อน tail -f เฝ้าไฟล์จน Control+C

Encoding

ภาษาไทยเพี้ยนให้ตรวจไฟล์ต้นทางและ encoding ก่อนสรุป Terminal เสีย UTF-8 BOM อ่านด้วย utf-8-sig ได้ แต่ระบบอื่นอาจใช้คนละ encoding

อ่าน log อย่างมีคำถาม

เริ่มจากเวลาที่เกิดปัญหาและชื่อขั้นตอน เช่นโหลด CSV หรือสร้าง HTML อ่านท้ายไฟล์ก่อน แล้วค้นคำ error ที่พบ เปิดช่วงบรรทัดใกล้เคียงเพื่อดูเหตุการณ์ก่อนหน้า ข้อความ ERROR ไม่ใช่ทุกอย่างของปัญหา บางโปรแกรมพิมพ์ traceback โดยไม่มีคำนั้น จึงต้องอ่านบริบทและ exit code ร่วมด้วย

ตัวอย่าง · อ่านผลก่อนทำขั้นถัดไป

ป้าย “ไฟล์” ให้วางใน editor ส่วนป้าย “Terminal” พิมพ์ใน shell อ่านผลกระทบก่อนคัดลอก และรันทีละบรรทัดเมื่อยังไม่คุ้น

Terminal · เขียนทับไฟล์

สร้าง log

printf "INFO start\nERROR missing field\nINFO done\n" > demo.log

ใน ~/mac-lab เท่านั้น \n ขึ้นบรรทัด > ทับ demo.log ถ้ามี

Terminal · อ่านข้อมูล

หา error

grep -n "ERROR" demo.log

-n เลขบรรทัด ผล 2:ERROR missing field

Terminal · อ่านข้อมูล

อ่านแบบเลื่อน

less demo.log

/ERROR ค้น n ถัดไป q ออก

Terminal · อ่านข้อมูล

ดูท้ายสองบรรทัด

tail -n 2 demo.log

ได้ ERROR และ INFO done

Terminal · อ่านข้อมูล

หา CSV

find . -name "*.csv"

เริ่มที่ . ค้นชื่อ หากยังไม่มีผลว่างปกติ

Terminal · อ่านข้อมูล

นับ INFO

grep "INFO" demo.log | wc -l

ส่งสองบรรทัดให้ wc -l ได้ 2

Terminal · เปลี่ยน clipboard

เข้า clipboard

printf "Hello Mac" | pbcopy

Command+V ได้ Hello Mac แทน clipboard เดิม

Terminal · อ่านข้อมูล · ต้องมี rg

ค้นด้วย ripgrep

rg -n "ERROR" demo.log

ใช้เฉพาะที่ติดตั้งและอนุมัติแล้ว -n เลขบรรทัด ถ้าไม่มีก็ใช้ grep ข้างบนได้

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
