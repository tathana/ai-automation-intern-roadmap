03 · หน้าต่าง Spaces จอนอก

จัด editor ข้างคู่มือก่อนแล้วค่อยเพิ่มพื้นที่ แยกงานอย่างที่ตามหาได้

ในหน้านี้สองหน้าต่างSpacesหาแอปจอนอกแชร์จอจัดโต๊ะเขียนโค้ดหนึ่งงาน

สองหน้าต่าง

เลื่อนเมาส์ค้างปุ่มเขียวดูตัวเลือกจัดหน้าต่าง ถ้าไม่ตรงใช้เมนู Window หรือปรับขอบด้วยมือ ไม่จำเป็นต้อง full screen ทุกแอป

Spaces

Full screen อาจอยู่ใน Space แยก Control+ลูกศรขึ้นเปิด Mission Control เมื่อใช้ค่ามาตรฐาน ดูภาพรวมและเลือกหน้าต่าง เริ่ม Desktop จำนวนน้อยก่อน

หาแอป

Command+Tab แล้วดูเมนู Window หากไม่มีหน้าต่างใช้ File → New/Open ตามแอป ไม่ต้องติดตั้งใหม่

จอนอก

Settings → Displays เลือก Mirror ภาพเหมือนกันหรือพื้นที่เพิ่ม จัดตำแหน่งให้ตรงโต๊ะ ถ้าไม่ขึ้นตรวจสาย อะแดปเตอร์ และ input จำนวนจอรองรับขึ้นกับรุ่นและอุปกรณ์

แชร์จอ

เลือกหน้าต่างงานเฉพาะเมื่อทำได้ ตรวจ preview ก่อนแชร์ ถ้าไม่ขึ้นดูสิทธิ์ screen recording และนโยบายบริษัท

จัดโต๊ะเขียนโค้ดหนึ่งงาน

เปิด Folder ใน editor ทางซ้าย เปิดเอกสารทางขวา ให้ Terminal อยู่ด้านล่างของ editor เพื่อเห็นคำสั่งและโค้ดพร้อมกัน ถ้าอักษรเล็กให้เพิ่มขนาดในแอปก่อนเปลี่ยนความละเอียดทั้งจอ เมื่อเริ่มประชุมกลับดู preview การแชร์อีกครั้ง เพราะจอที่เลือกอาจไม่ใช่จอที่มีหน้าต่างงาน

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
