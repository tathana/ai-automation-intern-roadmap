APPLE SILICON M1 · เรียนทีละขั้น / เปิดค้นตอนใช้งาน

01 · จาก Windows มา Mac

เริ่มจากเปิดแอป สลับงาน และบันทึกไฟล์ ไม่ต้องจำทุกเมนูวันแรก

ในหน้านี้ปุ่มหลักเมนูด้านบนปิดกับออกFinder และ Dockฝึกจริงวันแรกที่เปิดไฟล์จากแชต

ปุ่มหลัก

⌘ Command ใช้คัดลอกและบันทึกในหลายแอป ⌥ Option เป็นปุ่มเสริม ⌃ Control มีหน้าที่ต่างหาก ใน Terminal Control+C หยุดโปรแกรม ส่วน Command+C คัดลอกข้อความที่เลือก

เมนูด้านบน

เมนู File/Edit เป็นของแอปที่ active คลิกหน้าต่างก่อนดูเมนู Settings ของแอปมักอยู่ใต้ชื่อแอป และหลายแอปใช้ Command+, ได้

ปิดกับออก

Command+W หรือปุ่มแดงปิดหน้าต่าง/แท็บตามแอป Command+Q ออกจากแอป ถ้าปิดหน้าต่างแล้วแอปยังอยู่เป็นเรื่องปกติของหลายแอป ดูชื่อแอปก่อนกด Q

Finder และ Dock

Finder จัดไฟล์คล้าย Explorer Dock เปิดและสลับแอป คลิกขวาไอคอน → Options → Keep in Dock เก็บทางลัด เอาไอคอนออกจาก Dock ไม่ใช่ถอนแอป

ฝึกจริง

Command+Space ค้น Terminal แล้ว Enter เปิด Finder ต่อแล้ว Command+Tab สลับกลับ ถ้าค้นไม่พบตรวจ Applications ก่อนคิดว่าระบบเสีย

วันแรกที่เปิดไฟล์จากแชต

ดาวน์โหลดผ่านช่องทางที่อนุญาต → เปิด Downloads ใน Finder → เลือกไฟล์กด Command+I ดูชื่อและชนิด → ย้ายไปโฟลเดอร์งาน → เปิดด้วยแอปที่เหมาะ ถ้าเป็น source project เปิดทั้ง Folder ใน editor แทนดับเบิลคลิกไฟล์กระจัดกระจาย ผลที่ต้องการคือรู้ว่าไฟล์จริงอยู่ที่ใดและแก้สำเนาไหนอยู่

ลองอธิบายให้ตัวเองฟัง

เลือกหนึ่งขั้นตอนในบทนี้ บอกว่าทำเพื่ออะไร ต้องเริ่มจากที่ไหน และตรวจอย่างไรว่าสำเร็จ ถ้ายังตอบไม่ได้ ให้กลับไปอ่านคำอธิบายส่วนนั้นก่อนทำกับไฟล์งานจริง
