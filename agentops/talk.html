เล่าความคืบหน้าอย่างตรงไปตรงมา

สิ่งที่ทำแล้ว สิ่งที่ยังติด และขั้นถัดไป ไม่อ้างว่าจบทุก Module

ขอบเขตหลักฐาน บทเรียนอธิบายแนวคิดด้วยตัวอย่างสมมติ ส่วนผลทดลองเดิมในหน้าแก้ปัญหาและบทพูดอิงคำบอกเล่าจากภาพ ไม่ใช่สถานะ AWS ล่าสุด

ถ้าถามว่าทำถึงไหน · ประมาณ 20 วินาที

ใช้เป็นโครง ไม่ต้องท่อง
ผมลองถึง Module 6 บางส่วนแล้วครับ Policy ตั้งค่าได้ แต่เคส $250 ยังตอบว่าคืนเงินสำเร็จ เลยยังยืนยันการบล็อกไม่ได้ครับ ส่วน evaluation ติด invalid spans และยังไม่ได้สร้าง online config ครับ

เล่าพร้อมหลักฐาน · ประมาณ 1 นาที

ใช้เป็นโครง ไม่ต้องท่อง
ผมลอง support agent บน Runtime ที่มี dev, staging และ prod แล้วครับ Module 5 สร้าง stack และเห็น policy ACTIVE กับ Gateway ENFORCE มี log เติมยอด 25000 cents แต่ ORD-1004 ยังตอบ Refund processed ทั้ง dev และ staging ผมจึงยังไม่สรุปว่ากฎบล็อกถูกต้องหรือคืนเงินจริง อยากตาม decision กับ tool result ครับ Pipeline ที่เห็นผ่านถึง staging แต่ ApproveProd ยังรอ ณ ตอนนั้น ส่วน Module 6 เรียก prod แล้ว ORD-1002 ถูกปฏิเสธด้วยเหตุผล 45 วันเกิน 30 วัน แต่ประเมิน session ติด invalid spans และยังไม่ได้สร้าง online evaluation ครับ

ถามผู้สอนได้ทันที

  1. Policy เป็น ACTIVE และ Gateway อยู่ใน ENFORCE แต่คำขอ $250 ยังได้คำตอบว่าผ่าน ควรดู decision log หรือ request context ตรงไหนก่อนครับ?
  2. ตรวจว่า order_total_cents ที่ interceptor เติมถึง Cedar ด้วย type/path ถูกต้องได้อย่างไรครับ?
  3. ลำดับ interceptor กับ policy ในแล็บรุ่นนี้เป็นอย่างไร และดู trace จุดไหนครับ?
  4. invalid spans ควรเปิด trace/log group ไหน มี span ที่ evaluator รับได้ให้เทียบไหมครับ?
  5. EvalGate ครอบคลุมเคสเกินวงเงินไหม และทดสอบ Runtime version ไหนครับ?
  6. ภาพรอ ApproveProd อยู่ ถ้าจะตรวจแบบอ่านอย่างเดียวว่า prod ชี้ version ไหน ควรดู field ใดครับ?

ก่อนวันอังคาร

  • เปิดสรุปกับ checklist แยกหลักฐาน dev/staging/prod ตามเวลา
  • เตรียมภาพเดิมในช่องทางที่อนุญาต ไม่ใส่ credentials/identifiers จริงลงเว็บ
  • จด expected / observed / next check ของสองปัญหา
  • เริ่มคำถามที่ช่วยจับคู่เส้นทางคำขอ ไม่ต้องเล่าทฤษฎีทั้งหมดก่อนถาม
นอบน้อมและชัด

“ผมแยกสิ่งที่เห็นกับสิ่งที่ยังพิสูจน์ไม่ได้แล้วครับ อยากตรวจว่า context ถึง policy อย่างไร ถ้าพี่ชี้จุดดู decision ของคำขอนี้ได้ ผมจะไล่หลักฐานต่อครับ”
