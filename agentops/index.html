เข้าใจ AI Agent และ CI/CD ตั้งแต่พื้นฐาน

อ่านให้รู้ว่าส่วนไหนทำอะไร จับคำอังกฤษได้ และคุยกับทีมอย่างเข้าใจ

ขอบเขตหลักฐาน บทเรียนอธิบายแนวคิดด้วยตัวอย่างสมมติ ส่วนผลทดลองเดิมในหน้าแก้ปัญหาและบทพูดอิงคำบอกเล่าจากภาพ ไม่ใช่สถานะ AWS ล่าสุด

เริ่มจากเข้าใจระบบ แล้วค่อยอ่านคำสั่ง

AgentOps คือการพัฒนา ทดสอบ ส่งเวอร์ชัน และติดตาม AI agent เพื่อให้ทำงานได้อย่างตรวจสอบได้ ถ้ายังไม่รู้ API, Git หรือ pipeline เริ่มจากบทพื้นฐานด้านล่างได้เลย

เริ่มเรียนพื้นฐาน 9 หัวข้อ →

สองเส้นทางที่ต้องแยก

ตอนผู้ใช้ขอให้ทำงาน

ผู้ใช้ → agent ที่กำลังรัน → เลือกเครื่องมือ → ตรวจข้อมูลและสิทธิ์ → ได้ผลเครื่องมือ → ตอบผู้ใช้

นี่คือ request flow หรือเส้นทางคำขอ ใช้ดูว่า agent ทำงานถูกหรือไม่ ภาพนี้เป็นแนวคิด ไม่กำหนดลำดับภายในของ AWS service ทุกตัว

ตอนนักพัฒนาเปลี่ยนเวอร์ชัน

แก้ source/prompt → เก็บ version → build/test/evaluation → staging → approval ตามทีม → prod

นี่คือ delivery flow หรือเส้นทางส่งเวอร์ชัน CI/CD ดูแลเส้นทางนี้ ไม่ได้ build ใหม่ทุกครั้งที่ผู้ใช้คุยกับ agent

เส้นทางอ่านสำหรับคนเริ่มจากศูนย์

  1. โปรแกรมและ API — request/response, JSON, schema
  2. Agent และ tool — โมเดลเลือกงาน แล้วโปรแกรมรันอย่างไร
  3. Git และ version — สิ่งที่เปลี่ยนและวิธีตามกลับ
  4. CI/CD — build/test/deploy, staging/prod, approval
  5. Evaluation — เกณฑ์ผ่านและ regression
  6. AWS — account/region/role และบริการแต่ละชั้น
  7. Policy — prompt กับการควบคุมสิทธิ์
  8. Trace และ debug — ตามปัญหาด้วยหลักฐาน
  9. อ่านอังกฤษ — กริยา คำสถานะ และประโยคถามผู้สอน

มีเวลา 20 นาที ให้อ่านอะไร

อ่าน API → Agent/Tool → CI/CD ก่อน แล้วลองอธิบายว่าลูกค้าส่งคำขอกับนักพัฒนาส่งเวอร์ชันต่างกันอย่างไร จากนั้นเปิด Mac + AWS CLI เพื่ออ่านคำสั่งเป็นชิ้น และ ห้องจำลอง เพื่อเชื่อมภาพ
