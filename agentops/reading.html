เตรียมวันอังคาร · AWS AGENT WORKSHOP

อ่านอย่างไรให้ตาม workshop ทัน

แบ่งอ่าน 3 รอบ พร้อมทางลัดสำหรับคนมีเวลา 30 นาที

ขอบเขตหลักฐาน บทเรียนอธิบายแนวคิดด้วยตัวอย่างสมมติ ส่วนผลทดลองเดิมในหน้าแก้ปัญหาและบทพูดอิงคำบอกเล่าจากภาพ ไม่ใช่สถานะ AWS ล่าสุด

เป้าหมาย: อธิบายได้ก่อนจำคำสั่ง

ไม่ต้องอ่านรวดเดียวทั้งเว็บครับ อ่านทีละรอบแล้วลองพูดด้วยภาษาตัวเองว่าแต่ละส่วนทำอะไร เวลาประมาณด้านล่างปรับตามจังหวะของตัวเองได้

มีแค่ 30 นาที เริ่มตรงนี้ →

รอบแรก · เข้าใจภาพรวม · ประมาณ 30 นาที

  1. หัวข้อ 1 · โปรแกรมและ API

    จับภาพว่าโปรแกรมส่ง request และรับ response อย่างไร

  2. หัวข้อ 2 · Agent และ Tool

    โมเดลเลือกเครื่องมือ แล้วโปรแกรมนำไปทำงานอย่างไร

  3. หัวข้อ 4 · CI/CD

    เวอร์ชันใหม่ผ่านการตรวจและส่งไปใช้งานอย่างไร

  4. บทเสริม · Deploy บน AWS

    โค้ดกลายเป็น agent ที่เรียกใช้งานได้อย่างไร แยก Build, Deploy และ Invoke

ถ้ามีเวลาน้อย ทำรอบนี้ก่อนก็พอ แล้วตอบสองคำถาม: ตอนลูกค้าคุยกับ agent เกิดอะไรขึ้น? และตอนนักพัฒนาแก้ agent แล้วส่งเวอร์ชันใหม่เกิดอะไรขึ้น?

แนวคำตอบสำหรับเช็กตัวเอง

คำขอผู้ใช้เข้าระบบที่รันอยู่แล้ว agent เลือกใช้เครื่องมือและตอบตามผล ส่วนการแก้เวอร์ชันใหม่ต้องเตรียมชุดรัน ตรวจคุณภาพ และส่งไปปลายทางตามขั้นตอนทีม CI/CD ไม่ได้ build ใหม่ทุกครั้งที่ผู้ใช้ส่งข้อความ

รอบสอง · รู้จักชิ้นส่วน · ประมาณ 30–40 นาที

  1. หัวข้อ 3 · Git / Version — รู้ได้อย่างไรว่ากำลังใช้โค้ดชุดไหน?
  2. หัวข้อ 5 · Evaluation — ใช้อะไรตัดสินว่า agent ทำงานดีพอ?
  3. หัวข้อ 6 · AWS — แต่ละบริการทำหน้าที่อะไร?
  4. หัวข้อ 7 · Policy — ระบบตัดสินอย่างไรว่าอนุญาตให้คืนเงิน?
  5. หัวข้อ 8 · Log / Trace — ถ้าทำงานผิดจะเริ่มตามจากไหน?

จากนั้นเปิด ห้องจำลอง เดินทีละขั้น ลองอธิบายสิ่งที่จะเกิดก่อนกดถัดไป และแยกผลที่คาดหวังจากผลที่รายงาน

รอบสาม · อ่านอังกฤษและคำสั่ง · ประมาณ 20 นาที

อ่าน หัวข้อ 9 · อ่านอังกฤษ แล้วต่อ Mac + AWS CLI เวลาเจอคำสั่งหรือประโยคให้จับ 4 ส่วน:

ทำอะไร → กับอะไร → ที่ไหน/เวอร์ชันไหน → ควรเห็นผลอะไร

Verify that the endpoint points to the intended version.

ตรวจว่า endpoint ชี้เวอร์ชันที่ต้องการ งานนี้คือดูความสัมพันธ์ endpoint กับ version ไม่ใช่สั่ง deploy ใหม่

ไม่ต้องรันคำสั่งจริงทุกอันระหว่างอ่าน ก่อนรันต้องรู้ว่าเป็น Terminal บน Mac หรือในแล็บ และคำสั่งมีผลกับอะไร

วิธีอ่านแต่ละหัวข้อ

  1. อ่านคำอธิบายกับตัวอย่างก่อน
  2. อ่านประโยคอังกฤษ ลองแปลเองก่อนดูคำแปล
  3. ตอบคำถามท้ายหัวข้อก่อนเปิดเฉลย
  4. จดเพียงสามบรรทัดในสมุดหรือโน้ตที่ใช้
