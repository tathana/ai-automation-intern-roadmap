3 เส้นทางตัวอย่าง

Data → Analysis → Report

บท 1, 5, 6, 8: รับ CSV/API ตรวจข้อมูล คำนวณ metric สร้างรายงานและรับมือรอบที่ข้อมูลไม่ครบ

รับคำขอ → ตรวจ → อนุมัติ → ส่งต่อ

บท 2, 7, 8, 9: แยกผลเสนอจากอำนาจอนุมัติจริง ตรวจการรันซ้ำและส่งต่อวิธีกู้คืน

เอกสารหรือข้อความ → ดึง → ตรวจ → ใช้ต่อ

บท 3, 5, 9: แยกอ่านตัวอักษร ดึงฟิลด์ และแปลงรูปแบบ กำหนด null/needs_review พร้อมเกณฑ์ทดสอบ ครอบคลุม OCR และข้อมูลสำหรับ chatbot
