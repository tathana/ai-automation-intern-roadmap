Prompt และคู่มือหน้างาน

ไปที่ Prompt พร้อมใช้ ↓
จำแค่นี้

ให้บริบทที่จำเป็น ระบุผลที่คาด ตรวจสิ่งที่ AI ทำ

1. อาการ2. หลักฐาน3. ขอบเขต4. แก้5. ตรวจซ้ำ

ทฤษฎีที่ใช้ทำงาน

เมื่อเจอ error

ส่งเป้าหมาย expected/actual ขั้นตอนทำซ้ำและ error ที่ตัดข้อมูลลับแล้ว ชี้ไฟล์หรือฟังก์ชัน ไม่ต้องสั่งเขียนใหม่ทั้งหมด

ให้ฟีดแบ็กชัด

บอกข้อที่ผิดพร้อมตัวอย่าง ระบุสิ่งเดิมที่ต้องรักษา และให้ตรวจ regression ที่เกี่ยวข้อง คำว่า “ไม่ดี” ไม่ช่วยชี้สาเหตุ

เปลี่ยนแชทหรือส่งต่อ

สรุปเป้าหมาย requirement ล่าสุด ไฟล์ การตัดสินใจ ผลทดสอบ ปัญหาค้าง และ next step แยกสิ่งที่ยืนยันกับสมมติฐาน

ศัพท์ที่ควรรู้

Requirement=ข้อกำหนด; Constraint=ข้อจำกัด; Acceptance criteria=เกณฑ์รับงาน; Expected/Actual=ผลที่คาด/จริง; Side effect=ผลที่เกิดกับภายนอก; Schema=โครงข้อมูล; Retry=ลองใหม่; Handoff=ส่งมอบ

ถามให้ตรงคน

เจ้าของงานยืนยันนิยามธุรกิจ พี่เลี้ยงช่วยมาตรฐานโค้ด IT ดูเครื่องและสิทธิ์ AI ช่วยจัดคำถาม แต่ยืนยันกฎบริษัทแทนผู้รับผิดชอบไม่ได้

ก่อน–หลัง: ทำโจทย์ให้ตรวจได้

ยังคลุมเครือ

มันพัง แก้ใหม่ทั้งหมด

ชัดขึ้น

input นี้ได้ยอด 100 แต่คาด 80 ขอแก้เฉพาะเลือกยอดหลังลด รักษา output และเพิ่มเคสทดสอบนี้

สรุปส่งต่อเมื่อเริ่มแชทใหม่

เป้าหมายและผู้ใช้: ...
Requirement ล่าสุด: ...
ไฟล์/ส่วนที่เกี่ยวข้อง: ...
การตัดสินใจที่ตกลงแล้ว: ...
ผลทดสอบที่รันจริง: ...
สิ่งที่ยังไม่รู้และปัญหาค้าง: ...
งานถัดไป: ...
ขอบเขตที่อนุญาตให้ทำ: ...

ให้ AI สรุปได้ แต่คุณต้องตรวจว่าไม่ได้เปลี่ยนสมมติฐานเป็นข้อเท็จจริงก่อนใช้ต่อ

Prompt พร้อมปรับใช้

เติม [วงเล็บ] ด้วยบริบทที่อนุญาต เลือกใช้ภาษาไทยหรืออังกฤษตามทีม

Prompt ภาษาไทย

ช่วยวิเคราะห์และแก้ [ไฟล์/ส่วนงาน]
เป้าหมาย: [พฤติกรรม]
Expected: [ผลที่คาด]
Actual: [ผลจริง]
วิธีทำซ้ำและ input จำลอง: [ระบุ]
สิ่งที่ลองแล้วและผล: [ระบุ]
แก้เฉพาะ [ส่วน] รักษา [พฤติกรรมเดิม]
เสนอสมมติฐานจากหลักฐาน แล้วแก้พร้อม regression test
รายงานผลรันจริงและสิ่งที่ยังไม่ทราบ

Prompt English

Diagnose and fix [file/component].
Goal: [behavior]
Expected: [expected result]
Actual: [observed result]
Reproduction and synthetic input: [details]
Already tried and results: [details]
Change only [area], preserving [behavior].
State evidence-based hypotheses, then fix and add relevant regression tests.
Report actual results and remaining unknowns.

เมื่อเจอปัญหา

บริบทปนเวอร์ชัน

สาเหตุที่เป็นไปได้: ส่งหลายรอบไม่บอกล่าสุด

ตรวจต่อ: สรุปไฟล์และ requirement ปัจจุบัน

คิดว่ารันแล้วทั้งที่แนะนำ

สาเหตุที่เป็นไปได้: แชตกับเครื่องมือรันมีสิทธิ์ต่างกัน

ตรวจต่อ: ขอไฟล์ที่แก้และผลรัน ถ้าไม่มีให้ถือว่ายังไม่ยืนยัน

ถามพี่อย่างไร

ผมสรุปสิ่งที่ลองและผลแล้วครับ รบกวนชี้ว่าควรตรวจตรงไหนต่อครับ

ก่อนข้ามไปขั้นต่อไป

  • ตัดข้อมูลไม่อนุญาต
  • expected/actual ชัด
  • ขอบเขตชัด
  • รายงานตรงจริง
