ซ้อมกดหน้าจออังกฤษ: จากห้องเรียนถึง Guardrails

ลองเดินเส้นทางเดียวให้ครบ ตั้งแต่ myClass → ห้องแล็บ → AWS Console → Bedrock → Guardrails → ทดสอบ → ดูเหตุผล หน้าเว็บนี้ตอบสนองต่อการคลิก แต่ไม่ใช้บัญชี AWS และไม่สร้างทรัพยากร

ขอบเขต: ชื่อปุ่ม Bedrock Guardrails เช่น Select model, Run, Final response, View trace อ้างอิง คู่มือ AWS ส่วนหน้า myClass, ห้องแล็บ และการจัดวางภาพรวมเป็นแบบจำลอง หน้าคลาสจริงอาจต่างกัน ให้ยึดใบงานผู้สอน
