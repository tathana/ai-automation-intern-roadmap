ศัพท์หลัก

AI

อ่านว่า: เอไอ

ระบบที่ทำงานบางอย่างคล้ายความสามารถมนุษย์ เช่น จำแนกหรือสร้างข้อความ

Machine Learning (ML)

อ่านว่า: แมชชีน เลิร์นนิง

ให้เครื่องเรียนรูปแบบจากข้อมูลเพื่อทำนายหรือจัดประเภท

Generative AI

อ่านว่า: เจเนอเรทีฟ เอไอ

AI ที่สร้างข้อความ ภาพ เสียง หรือเนื้อหาใหม่

Foundation Model (FM)

อ่านว่า: ฟาวน์เดชัน โมเดล

โมเดลพื้นฐานที่ฝึกมาแล้วและนำไปใช้ได้หลายงาน

Large Language Model (LLM)

อ่านว่า: ลาร์จ แลงกวิจ โมเดล

โมเดลภาษาขนาดใหญ่สำหรับอ่าน เขียน และตอบข้อความ

Inference

อ่านว่า: อินเฟอเรนซ์

การเรียกโมเดลให้สร้างผลลัพธ์จากอินพุตหนึ่งครั้ง

Prompt

อ่านว่า: พรอมป์ต์

คำสั่งและข้อมูลที่ส่งให้โมเดล

Prompt engineering

อ่านว่า: พรอมป์ต์ เอนจิเนียริง

การออกแบบและปรับคำสั่งให้เหมาะกับงาน

Token

อ่านว่า: โทเคน

หน่วยย่อยของข้อความที่โมเดลประมวลผล

Embedding

อ่านว่า: เอ็มเบดดิง

ชุดตัวเลขที่แทนความหมายของข้อมูลเพื่อใช้ค้นหรือเปรียบเทียบ

Vector store

อ่านว่า: เวกเตอร์ สโตร์

ที่เก็บ embedding เพื่อค้นข้อมูลใกล้เคียงทางความหมาย

Multimodal

อ่านว่า: มัลติโหมดัล

ทำงานกับข้อมูลหลายรูปแบบ เช่น ข้อความและภาพ

Use case

อ่านว่า: ยูสเคส

กรณีใช้งานที่ระบุผู้ใช้ ปัญหา และผลลัพธ์ชัดเจน

Amazon Bedrock

อ่านว่า: แอมะซอน เบดร็อก

บริการ AWS สำหรับใช้โมเดลและสร้างแอป Generative AI

Amazon Nova 2

อ่านว่า: แอมะซอน โนวา ทู

ตระกูลโมเดลของ Amazon ที่ระบุในโครงร่างหลักสูตรปี 2026

Playground

อ่านว่า: เพลย์กราวนด์

หน้าทดลองส่ง prompt และดูผลจากโมเดลใน Console

Model catalog

อ่านว่า: โมเดล แค็ตตาล็อก

หน้าดูและเลือกโมเดลที่บริการรองรับ

Temperature

อ่านว่า: เท็มเพอเรเชอร์

การตั้งค่าความหลากหลายของผลลัพธ์ในโมเดลที่รองรับ

Hallucination

อ่านว่า: ฮัลลูซิเนชัน

คำตอบที่โมเดลแต่งขึ้นหรือผิดแม้ดูน่าเชื่อ

Responsible AI

อ่านว่า: รีสพอนซิเบิล เอไอ

แนวทางใช้ AI โดยคำนึงถึงความถูกต้อง ความเป็นธรรม ความปลอดภัย และคนที่ได้รับผล

Guardrail

อ่านว่า: การ์ดเรล

กฎช่วยตรวจและคุมอินพุตหรือผลลัพธ์ของ AI

Denied topic

อ่านว่า: ดีไนด์ ทอปปิก

หัวข้อที่ตั้งให้ Guardrail ปฏิเสธตามบริบท

Word filter

อ่านว่า: เวิร์ด ฟิลเตอร์

กฎตรวจคำหรือวลีที่กำหนด

Trace

อ่านว่า: เทรซ

ข้อมูลร่องรอยว่าระบบประมวลผลหรือบล็อกอย่างไร

RAG

อ่านว่า: แร็ก

ค้นข้อมูลที่เกี่ยวข้องก่อน แล้วใช้ข้อมูลนั้นช่วยสร้างคำตอบ

Knowledge Base

อ่านว่า: นอลเลจ เบส

แหล่งเอกสารที่เตรียมให้ระบบค้นประกอบคำตอบ

Citation

อ่านว่า: ไซเทชัน

แหล่งอ้างอิงที่แสดงว่าคำตอบมาจากเอกสารใด

Agent

อ่านว่า: เอเจนต์

ระบบ AI ที่ช่วยเลือกขั้นตอนและอาจเรียกใช้เครื่องมือ

AgentCore

อ่านว่า: เอเจนต์คอร์

ชุดความสามารถ AWS สำหรับสร้างและดูแล Agent

IAM

อ่านว่า: ไอแอม

ระบบจัดการตัวตนและสิทธิ์ของ AWS

Region

อ่านว่า: รีเจียน

พื้นที่ให้บริการ AWS ที่เลือกใช้งาน

AccessDenied

อ่านว่า: แอ็กเซส ดีไนด์

ข้อผิดพลาดเมื่อไม่มีสิทธิทำขั้นตอนนั้น

Sandbox

อ่านว่า: แซนด์บ็อกซ์

สภาพแวดล้อมทดลองที่แยกจากระบบใช้งานจริง

PoC

อ่านว่า: พีโอซี

ต้นแบบเล็กเพื่อพิสูจน์ว่าแนวคิดทำได้

Evaluation

อ่านว่า: อีแวลูเอชัน

การวัดคุณภาพด้วยเกณฑ์และชุดทดสอบ

Governance

อ่านว่า: กัฟเวอร์แนนซ์

กติกา เจ้าของ และผู้รับผิดชอบในการใช้งาน

Compliance

อ่านว่า: คอมพลายแอนซ์

การทำตามข้อกำหนดที่เกี่ยวข้อง

ศัพท์เพิ่มสำหรับอ่านผลแล็บ

Source chunk · ซอร์ส ชังก์

ข้อความส่วนเล็กจากเอกสารที่ Knowledge Base ค้นมาให้โมเดล ควรเปิดดูว่าตรงคำถามจริงหรือไม่

Working draft · เวิร์กกิง ดราฟต์

ฉบับทดลองที่แก้กฎ Guardrail ได้ ก่อนสร้าง version สำหรับใช้งาน

False positive · ฟอลส์ พอซิทีฟ

กฎบล็อกคำถามที่ควรผ่าน เช่น บล็อกเรื่องใบรับรองแพทย์เพราะเห็นคำว่าแพทย์

False negative · ฟอลส์ เนกะทีฟ

กฎปล่อยผ่านคำถามที่ควรบล็อก ต้องทดสอบด้วยตัวอย่างหลายแบบ

Retrieved reference · รีทรีฟด์ เรเฟอเรนซ์

แหล่งข้อความที่ระบบค้นพบเพื่อนำไปประกอบคำตอบ

ประโยคอังกฤษที่ใช้ขอให้ผู้สอนช่วย

ประโยคพูดแปลไทยใช้เมื่อ
Could you repeat the last step, please?รบกวนทวนขั้นตอนล่าสุดอีกครั้งได้ไหมครับฟังไม่ทัน
Which Region should I use?ผมควรเลือก Region ไหนครับไม่เห็นโมเดลหรือทรัพยากร
I cannot see the model in the catalog.ผมไม่เห็นโมเดลในรายการครับรายการโมเดลต่างจากผู้สอน
I get an AccessDenied error at this step.ขั้นตอนนี้ขึ้นว่าไม่มีสิทธิ์ครับบัญชีแล็บติดสิทธิ์
Is this the expected output?ผลลัพธ์นี้ตรงที่ควรได้ไหมครับคำตอบโมเดลไม่เหมือนตัวอย่าง
Should I use the provided lab account?ผมควรใช้บัญชีแล็บที่ให้มาใช่ไหมครับมีหลายบัญชีเปิดค้าง
Where can I find the lab instructions?ผมหาใบงานแล็บได้ที่ไหนครับเข้าห้องแล้วไม่เห็นโจทย์
