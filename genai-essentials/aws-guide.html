DAY-OF-CLASS GUIDE · อ้างอิงอีเมลลงทะเบียนที่คุณได้รับ

เว็บไหนใช้ทำอะไรในวันอบรม

มีอย่างน้อยสามพื้นที่ที่หน้าตาและหน้าที่ต่างกัน: บัญชีเรียน, หน้าห้องเรียน, และสภาพแวดล้อมแล็บ อย่าสับสนระหว่างการเข้าเรียนกับการเปิด AWS Console

พื้นที่ใช้ทำอะไรเมื่อไร
AWS Skill Builderบัญชีผู้เรียนและเนื้อหาฝึกอบรม เข้าด้วย AWS Builder ID ตามอีเมลที่คุณได้รับก่อนวันอบรม ลองเข้าสู่ระบบ
myClass dashboardดูคลาสที่ลงทะเบียนและเข้าห้องเรียนออนไลน์เช้าวันอบรม เปิด Enrolled classes แล้วกด Join Training เมื่อปุ่มขึ้น
ห้องแล็บที่ผู้สอนให้บัญชีชั่วคราว คำสั่งแล็บ และจุดส่งงาน อาจอยู่ในแพลตฟอร์มฝึกของ AWSเปิดตามคำแนะนำในห้องเรียนเท่านั้น
Amazon Bedrock Consoleหน้าจอจริงสำหรับโมเดล Playground, Guardrails และ Knowledge Basesเข้าเมื่อผู้สอนให้บัญชีและสิทธิสำหรับแล็บ

ก่อนวันอบรม: ตรวจบัญชีทีละข้อ

  1. เปิดอีเมล “You've been added to AWS Skill Builder” จาก no-reply@aws.training ที่คุณแนบไว้ แล้วใช้อีเมลผู้รับเดียวกันในการเข้าสู่ระบบ
  2. เข้า Skill Builder ด้วยตัวเลือก AWS Builder ID ตามคำแนะนำในอีเมล ถ้ายังไม่มี Builder ID ให้ดำเนินการสร้างตามหน้าจอที่ AWS แสดง
  3. เปิด myClass แล้วมองหา Enrolled classes หรือชื่อหลักสูตร Generative AI Essentials on AWS
  4. ตรวจวันและเวลาในหน้าคลาส: 27 ตุลาคม 2026 เวลา 09:00–17:00 Asia/Bangkok ตามอีเมล AWS ที่คุณได้รับ
  5. ทดสอบเสียง หูฟัง และเบราว์เซอร์ เช็กว่าเข้าอีเมลและ myClass ได้ โดยยังไม่ต้องสร้าง AWS account ส่วนตัวเพื่อทำแล็บ
อีเมลภาษาไทยพิมพ์ว่า “Monday 27 October 2026” แต่วันที่ 27 ตุลาคม 2026 ตรงกับวันอังคาร ให้ตรวจวันที่ใน myClass หรือสอบถามผู้ประสานงานก่อนวันเรียน

เมื่อเข้าห้องแล็บ: อ่านหน้าจอ 6 จุดนี้ก่อนกด

  1. Instruction / Lab guide: ใบงานที่บอกว่าต้องทำอะไรและจะส่งผลอย่างไร
  2. Start Lab / Lab status: เริ่มหรือดูว่าสภาพแวดล้อมพร้อมหรือยัง
  3. Open AWS Console: เปิด Console ของบัญชีแล็บ อย่าสลับไปบัญชีส่วนตัวที่เคยเปิดค้าง
  4. Region: พื้นที่ด้านบน Console เช่น Region ที่ใบงานกำหนด ถ้าเลือกผิดอาจไม่เห็นทรัพยากรหรือโมเดล
  5. Service navigation: ค้นหา Amazon Bedrock แล้วเลือก Playground, Guardrails หรือ Knowledge Bases ตามใบงาน
  6. Submit / Check / End Lab: ปุ่มตรวจหรือจบงานของแพลตฟอร์มแล็บ ทำเมื่อใบงานให้ทำเท่านั้น

ในบางคลาสผู้สอนอาจเตรียมโมเดล Guardrail หรือ Knowledge Base ให้แล้ว ถ้าใบงานบอกให้ “ใช้ของที่มี” ไม่ต้องสร้างใหม่
