เริ่มต้นและ Workbook

รู้ว่าตอนนี้อยู่ด่านไหน และใช้สมุดงานไฟล์เดียวพาโปรเจกต์เดินต่อ

1 — เข้าใจโจทย์และกำหนดขอบเขต

สำรวจงานเดิม ตั้ง baseline เขียน scope, acceptance criteria และ traceability

เปิดขั้นนี้ →03

2 — ออกแบบระบบและแบ่งงาน

สำรวจ data/risk วาง architecture, contracts, project structure และ vertical slices

3 — เริ่มเขียนโค้ดทีละก้อน

เชื่อม requirement ไปยังไฟล์ ฟังก์ชัน test และวงจรทำงานรายวัน

เปิดขั้นนี้ →05

4 — ใช้ AI ช่วยเขียนอย่างคุมงานได้

Prompt สำหรับแบ่งงาน เขียนฟังก์ชัน Debug และ Review โดยไม่ยกการตัดสินใจให้ AI

เปิดขั้นนี้ →06

5 — วาง Test และ Failure Cases

เปลี่ยน acceptance เป็น unit/integration tests และแยก software test จาก AI evaluation

เปิดขั้นนี้ →07

6 — Release, Observe และ Handoff

เปิดใช้อย่างควบคุมได้ มี rollback, logs, runbook, demo และการวัดผล

เปิดขั้นนี้ →08
